1. Open CMD Prompt
2. Paste the following command:
```
wmic path softwareLicensingService get OA3xOriginalProductKey
```

3. You should get this input:
```
OA3xOriginalProductKey
NDD68-GYTB4-2P3MP-TT3BH-BDTBP
```

4. Your Product Key is: ==NDD68-GYTB4-2P3MP-TT3BH-BDTBP==
