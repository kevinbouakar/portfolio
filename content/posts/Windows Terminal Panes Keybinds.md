This file showcases my current key binds configuration for my tmux like Terminal movement.

- `ALT` + `UP/DOWN/LEFT/RIGHT` : Switches focus to selected pane.
- `ALT` + `SHIFT` + `_/+`: Creates a new pane horizontally/vertically  respectfully.
- `ALT` + `SHIFT` + `UP/DOWN/LEFT/RIGHT` : Resize selected pane.
